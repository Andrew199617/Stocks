How to read this

Each company gets a five-scenario owner's-earnings DCF (super bear / bear / base / bull / super bull, each with an assigned likelihood); growth fades over a moat-driven competitive advantage period. Wtd IRR = probability-weighted expected annual return at the current price. IV = probability-weighted intrinsic value per share at a 15% discount rate; Upside = IV vs price. Tiers: S ≥25% · A 20-25% · B 15-20% (clears the 15% hurdle) · C 10-15% · D <10% · F no positive owner's earnings.
